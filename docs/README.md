# Documentation

NetBox Custom Field Profiles organizes existing Device custom fields into reusable
profiles on a **Custom Fields** tab. The plugin stores profile configuration; field
definitions and values remain native NetBox data.

## Users and administrators

| Guide | Use it to |
|---|---|
| [User guide](user-guide.md) | Understand profiles, view/edit values and reduce main-page clutter |
| [Installation](installation.md) | Install, enable and update the plugin on a supported runtime |
| [Profile administration](administration.md) | Configure field selection, ordering, rules and permissions |
| [Troubleshooting](troubleshooting.md) | Diagnose missing tabs, save errors and JavaScript delivery problems |

Supports Devices; tested on **NetBox 4.7.4 / Docker packaging 5.1.1**. The declared
minimum is 4.7.0. Other versions have not been verified.
