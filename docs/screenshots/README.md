# README screenshots

Use real screenshots of the running plugin with sample data. These images are
intended for the public GitHub README. There are no screenshot assets yet.

Capture these two views at a desktop width (roughly 1440 pixels), keeping text
readable and excluding browser chrome:

1. **`parameters-tab.png`** — a Device’s Parameters tab with two or three matching
   sections and representative values. Include the Device heading and Edit
   Parameters button. A repeated field across two sections helps illustrate shared
   native values. Use a sample Device name and realistic example values.
2. **`profile-configuration.png`** — the Custom Field Profile editor showing its
   title, ordered Selected fields and at least one matching rule. If the form is
   tall, capture the relevant form area rather than shrinking the whole page.

Save the PNG files in this directory or attach them in the project conversation.
The main README has an HTML comment with the two prepared image links. Once real
images are available, move those links out of the comment and check their GitHub
rendering. Do not enable links before both target files exist.
