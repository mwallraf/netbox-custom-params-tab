# Edit Parameters

1. Implement a native partial Device ModelForm resolving the deduplicated current profile fields and native UI editability. Use native field widgets and validation, restricted reference querysets, initial values and stale-form protection.
2. Register a Device change-protected edit URL and a constrained edit action on Parameters. Reuse native transactional view saving/change logging. Lock Device on POST and preserve unrelated values.
3. Prove GET/POST tracer, duplicate handling, excluded field/property preservation, invalid required/type/choice data, hidden/read-only fields, profile changes, permissions, CSRF, stale submissions, reference constraints and native-write visibility in isolated tests.
4. Run focused tests, full plugin suite and required baseline. Update docs and final manual UAT checklist with observed automated results only.

Risks: forged excluded fields, hidden references, lost unrelated values and bypassed object permissions. Native form restriction and constrained transactional view are the boundaries; test actual responses and persisted values. No schema change or browser automation is required.
